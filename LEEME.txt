PASOS PARA USAR

1) Crear proyecto en Supabase.
2) Ir a SQL Editor y ejecutar el archivo supabase.sql.
3) Ir a Project Settings > API y copiar:
   - Project URL
   - anon public key
4) Abrir config.js y pegar esos datos.
5) Subir estos archivos a GitHub Pages.
